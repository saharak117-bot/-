FANUC LATHE SIMULATOR (MOBILE)
==============================

วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วย Chrome หรือเว็บเบราว์เซอร์
3. กด Run เพื่อดูภาพชิ้นงานหมุนและมีดเคลื่อนที่
4. แก้ G-code ในช่อง แล้วกด Reset จากนั้น Run
5. ใช้ Step เพื่อเดินโปรแกรมทีละบรรทัด

ตัวอย่างในไฟล์
- G00: เคลื่อนที่เร็ว
- G01: เคลื่อนที่ตัดตามแนวเส้นตรง
- G21/G18/G40/G99: ตั้งค่าพื้นฐาน
- G97 S500 M03: แสดงการหมุน spindle
- ปาดหน้า: เคลื่อน Z ไป 0 แล้ว X ไป 0
- กลึงเรียว: X20 Z0 ไป X10 Z-30
- เจาะรู: X0 เคลื่อน Z ลงไป Z-18 แล้วถอนกลับ

ข้อจำกัด
นี่คือภาพจำลองเพื่อฝึกอ่านเส้นทาง G-code เท่านั้น ไม่ใช่ CNC controller,
ไม่คำนวณเนื้อวัสดุที่ถูกตัดอย่างแม่นยำ, ไม่ตรวจชน, ไม่รองรับ canned cycle
เช่น G71/G72/G74/G76 หรือ offset จริง และไม่ส่งโปรแกรมไปเครื่อง CNC.
ตรวจสอบคู่มือ FANUC และให้ผู้สอนตรวจทุกโปรแกรมก่อนใช้กับเครื่องจริง.
