FANUC-STYLE LATHE TRAINING PANEL (offline)
วิธีใช้:
1) แตก ZIP
2) เปิด index.html ด้วย Chrome บนโทรศัพท์หรือคอมพิวเตอร์
3) เขียนคำสั่งฝึก SIM_ ในช่องโปรแกรม
4) กด ตรวจคำสั่ง แล้วกด RUN SIM เพื่อดูภาพจำลอง

คำสั่งฝึกที่รองรับ:
SIM_START
SIM_STOCK 100
SIM_TURN 70
SIM_STEP 45
SIM_END

ข้อจำกัดเพื่อความปลอดภัย:
นี่คือสื่อฝึกแบบจำลองหน้าจอคล้าย FANUC เท่านั้น ไม่ใช่ FANUC emulator
ไม่รองรับ G-code/M-code จริง ไม่สร้างไฟล์ NC และไม่เชื่อมต่อเครื่อง CNC
ห้ามนำคำสั่งฝึก SIM_ ไปใช้กับเครื่องจักรจริง
