LATHE VISUAL SIMULATOR — ZIP สำหรับ GitHub Pages

วิธีทดลอง
1) แตกไฟล์ ZIP
2) เปิด index.html ในเบราว์เซอร์ หรืออัปโหลดไฟล์ทั้งหมดเข้า repository ของ GitHub
3) เปิด Settings > Pages แล้วเลือก branch และโฟลเดอร์ root
4) เปิด URL เว็บไซต์จาก GitHub Pages
5) กด “เริ่มจำลอง” เพื่อดูภาพชิ้นงานและมีดกลึงเคลื่อนที่

การใช้งาน
- MOVE X=40 Z=0 : เคลื่อนที่โดยไม่แสดงการตัด
- CUT X=30 Z=-20 : แสดงการตัดแบบภาพประกอบ
- HOME : กลับตำแหน่งเริ่มต้น
- ใช้ ; นำหน้าบรรทัดหมายเหตุ
- กด “ทีละคำสั่ง” เพื่อไล่ดูทีละบรรทัด

ข้อจำกัดและความปลอดภัย
นี่เป็นเว็บจำลองภาพ 2D เพื่อการเรียนรู้เท่านั้น ไม่ใช่ CNC simulator ทางวิศวกรรม
ไม่รองรับ G-code หรือไวยากรณ์ FANUC จริง และคำสั่งในเว็บนี้ใช้กับเครื่องจักรจริงไม่ได้
ไม่เชื่อมต่อ USB, controller หรือเครื่อง CNC จริง
รูปทรงที่แสดงเป็นภาพประกอบ ไม่ใช้ตรวจสอบระยะตัด การชน หรือความปลอดภัย
