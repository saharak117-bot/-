FANUC 21i-TB CNC TRAINING — G21 / mm

วิธีใช้แบบไม่ใช้ GitHub:
1) แตกไฟล์ ZIP
2) เปิด index.html ด้วย Chrome
3) เลือกแบบฝึก แล้วกด "เริ่มจำลอง"
ใช้งานหน้าเว็บพื้นฐานได้แบบออฟไลน์

วิธีนำขึ้น GitHub Pages:
1) สร้าง repository ใหม่ในบัญชี GitHub ของคุณ
2) แตก ZIP แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมด (รวม .github ถ้ามี)
3) ไปที่ Settings > Pages
4) เลือก Deploy from a branch > main > /(root) แล้ว Save
5) รอ GitHub แสดง URL ของเว็บไซต์

ข้อจำกัดสำคัญ:
- เป็นสื่อฝึกแนวคิดหน้าตาคล้ายแผงควบคุมเท่านั้น
- ไม่ใช่ FANUC emulator และไม่ใช่เครื่องจำลองการตัดเฉือนจริง
- ไม่แปล/สร้าง G-code หรือ M-code ที่ใช้เดินเครื่องจริง
- ไม่เชื่อมต่อ USB, RS-232 หรือเครื่องจักร
- ห้ามใช้ผลจำลองนี้ตัดสินความปลอดภัยหรือความถูกต้องของงานจริง
