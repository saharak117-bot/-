TRUCK HAUL SIMULATOR — Android Web Prototype

วิธีเล่น:
1) แตกไฟล์ ZIP
2) เปิด index.html ด้วย Chrome บน Android (แนะนำเปิดผ่านเว็บโฮสต์/เว็บเซิร์ฟเวอร์ในเครื่อง หากเบราว์เซอร์บล็อกไฟล์)
3) เลือกรถ 10 หรือ 18 ล้อ และมุมมอง จากนั้นกดเริ่มขับ
4) ใช้ปุ่มบนหน้าจอ: ซ้าย/ขวา, คันเร่ง, เบรก, R/N/D, มุมกล้อง

หมายเหตุ:
นี่คือต้นแบบเกมเว็บที่เล่นได้ มีถนนจำลอง การควบคุม ความเร็ว เกียร์ และมุมมองสลับได้
ภาพและฟิสิกส์ยังเป็นแบบ 2D จำลอง ไม่ใช่เกม 3D สมจริงหรือเครื่องฝึกขับรถระดับอาชีพ
